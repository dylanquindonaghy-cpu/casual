What a casual sees on the Pay tab and on "Raise a pay query", now and after 28.10. Phones at their real 390px, light and dark; the laptop row is 1,280px wide at 150% scaling (an 853px window). Made-up firm and casual: Acme Events, Nell Hadley. A dashed blue outline marks what 28.10 adds.

  • The pay day shows first, before the code, as Home already shows it. Hours, rates and totals stay behind the code.
  • "6‑digit" uses a non-breaking hyphen, so it never splits across two lines.
  • The pay query asks for the code on its own page and comes straight back, with the shift she came for still chosen.

Pay, before the code

Raise a pay query, without the code

Before, the query sent her away to the pay page and she had to find her way back. After, the code step is on the query itself. Once the code is right she lands back on /pay/query?shift=… with her shift chosen; anything else in the address is dropped.

After the code
