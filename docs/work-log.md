# Work log

This file explains, in plain English, what was built in each work session, how long it took and
what it means for you. Each row of the "Hours log" table (`docs/plan/hours-log.md`) points to a
section here. The newest section is at the bottom. Hours are Claude's working time, measured from
the session history. Your own reading and approval time is not included.

---

**By month, since 2026-10-29 (P1.3):** the sections are in `docs/logs/`, one file a month, newest at
the bottom of each. Add each new section to the current month's file; in a new month, start a new
file like the others and list it here. Line numbers that older docs give for this file are its own
as it was before the cut.
